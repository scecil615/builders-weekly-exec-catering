# Business Builders Weekly Exec Catering

A simple, mobile-friendly catering decision dashboard for a weekly executive meeting. Built with vanilla HTML, CSS, and JavaScript as a first GitHub project.

## Features
- Editable headcount, total budget, tax, and delivery/tip estimates
- Six starter restaurant options with editable estimated prices
- Search, cuisine filters, and under-budget filtering
- Estimated meeting cost and remaining budget per restaurant
- Save a weekly pick and export saved history to CSV
- Browser-local persistence using `localStorage`

## Important limitations
- Starter restaurant prices are illustrative estimates, **not real-time quotes**
- Saved picks and custom restaurant edits exist only in the current browser/device
- No ordering, payment, voting, or shared sync is implemented
- Verify food allergies, delivery coverage, pricing, and catering minimums with vendors

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
Create a public GitHub repository, upload `index.html` and `README.md`, then go to Settings → Pages → Deploy from a branch → main → /(root) → Save.
